# Фактический вклад капитана

Не заполнено капитаном; соответствующий балл не подтверждён. Укажите только реальные действия и решения: исходная идея, задачи ассистенту, выбор/отклонение вариантов, ручные проверки, участие в подготовке или размещении. Для каждого — дата или период, действие, причина, доступное свидетельство. Не нужно приписывать себе ручное программирование, если его выполнял ИИ.
