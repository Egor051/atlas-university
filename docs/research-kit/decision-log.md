# Журнал решений после исследования

Пока нет результатов настоящего исследования. Для каждого решения заполнить: проблема; коды фактических наблюдений; сохранить/изменить/отложить; причина; затронутый сценарий; изменение; измеримый порог успеха; повторная проверка и дата. Не подменять наблюдения гипотезами или результатами автоматизации.
