## Границы подтверждения

Автоматический axe не заменяет полный аудит WCAG, проверку скринридером или испытание с людьми. Размер viewport не заменяет физический телефон. Временный отказ сети вводился намеренно и обозначен в отчёте; успешные API-ответы не подменялись. Происхождение текущих снимков и версии «до» описано в [screenshots/README](../screenshots/README.md).

Образы закреплены digest, Linux runtime — constraints lock. [Проверка зависимостей](dependency-review.md) охватывает известные Python-advisory на дату проверки, не неизвестные уязвимости или пакеты ОС. Тестовый HTTPS использует внутренний CA Caddy, переданный только процессу проверки. Это не свидетельство публичного сертификата ACME. В receipt указаны хеши проверенных файлов; это не вымышленный Git commit. Удалённый GitHub Actions подготовлен, но ещё не запускался.
