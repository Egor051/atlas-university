## Маршрут заказа

1. Студент открывает «Справки», выбирает вид документа и отправляет заказ. Сведения для приложения № 4 берутся из серверного учебного реестра. Ввести можно только выбор адресата из списка вымышленных комиссариатов и необязательный комментарий.
2. Учебный офис получает уведомление и открывает очередь «Справки». Подготовка приложения № 4 требует сверки сведений, отметки сотрудника и текущей версии заявки. Профсоюз и ВУЦ обрабатывают свои обращения по существующим правилам доступа.
3. При подготовке ATLAS сохраняет проверенные поля и ответ сотрудника в одной транзакции с изменением статуса. Студент получает адресное уведомление, открывает запись, смотрит историю, просматривает или скачивает HTML. Для демонстрации полного пути подходит аккаунт Марка Северина. У аккаунта Алины Ветровой доступна обычная справка с места учёбы.

В HTML по приложению № 4 поля идут в порядке официальной формы. Секции подписи, печати, штампа и регистрации обозначены как незаполненные. Сведения для дополнительного раздела о договоре военной подготовки в учебном реестре отсутствуют, поэтому он остаётся пустым.

## Данные и совместимость

- Миграция `0011_certificate_issues` добавляет `certificate_enrollments` и `certificate_issues`. Первый реестр содержит подтверждённые внутри сценария сведения. Вторая таблица хранит поля результата на момент подготовки, идентификатор сотрудника и время подготовки.
- `GET /api/requests/types`, `GET /api/requests` и `GET /api/staff/requests` поддерживают `kind=all|request|certificate`. Прежний список API по умолчанию включает оба вида, а оба раздела интерфейса запрашивают свой вид. Доступ к истории, отправке и результатам проверяется сервером.
- Заказ приложения № 4 использует `POST /api/requests` с типом `military_appendix_4` и полем `details.commissioner`. При переводе такого заказа в `ready` требуется `confirmed_enrollment: true` и актуальная `expected_version`.
- Результат выдаёт `GET /api/requests/{id}/document`. Параметр `preview=true` открывает результат в отдельной вкладке. Готовые заявки старого типа «Справка для воинского учёта» остаются в истории как прежние результаты.
- Существующие черновики заказов справок переносятся в `certificate-order`. Назначение других черновиков и ключи повтора сохраняются.
