# Приёмка публичного ATLAS Campus 3.2.1 — 11 ноября 2026

Техническая приёмка пройдена. [Публичный стенд](https://atlas-university.ru/) — неофициальный конкурсный концепт, все аккаунты, записи и документы вымышлены. [Адрес с www](https://www.atlas-university.ru/) ведёт на основной домен.

В Yandex Cloud работает сборка `c273de52957f023e`, версия `3.2.1`, из коммита [`60b9ebe3d5a61fc0949de103aa0bd1f143c41a6c`](https://github.com/Egor051/atlas-university/commit/60b9ebe3d5a61fc0949de103aa0bd1f143c41a6c) ветки `main`. Коммит проверен по метке реально запущенного образа, build — по `/api/health` с публичного адреса. Документы и инструменты приёмки могут обновляться в `main` отдельно от образа. Временные метки JSON даны в UTC, дата приёмки — по МСК.

Штатный установщик агента Yandex Cloud при загрузке возвращает код `3`: его скрипт запускает агент без ожидания и сразу запрашивает статус, пока служба ещё не активна. Установленный `unified_agent.service` затем работал. Этот статус был до установки ATLAS; ATLAS использует отдельный мониторинг. В проверенном интервале после reboot у web не было 5xx или критических трассировок, у PostgreSQL — PANIC/ERROR/FATAL, у Caddy — error. Краткие 502 во время намеренных остановок относятся к отдельной проверке восстановления.

## Что нужно владельцу

1. Подтвердить, что оплата Yandex Cloud, домен и закрепление IPv4 обеспечены по 28 ноября включительно. Назначить ответственного и проверить доставку уведомлений GitHub Actions для этого репозитория. Будущая доступность не следует из успешного запуска мониторинга.
2. Для ручного подтверждения с телефона отключить VPN и прокси, открыть [прототип](https://atlas-university.ru/) и [готовность](https://atlas-university.ru/api/ready). На странице входа выбрать Алину, открыть расписание и оценки, затем «Заявки → Готово» и скачать вымышленный документ №4. В отдельном приватном окне выбрать Марка и проверить другую группу. При необходимости пройти свой помеченный тестовый путь через сотрудника по [руководству жюри](jury-guide.md). Записать дату, регион и оператора без IP и личных данных. Такой проход дополняет сетевые пробы, включая реальный телефон и сенсорное управление.
3. Передать жюри [публичную ссылку](https://atlas-university.ru/), [репозиторий](https://github.com/Egor051/atlas-university), демоаккаунты из [руководства](jury-guide.md) и [описание процесса](process.md). Отправка конкурсной работы — действие капитана.

Руководство по серверу: [развёртывание](deployment.md) и [эксплуатация](operations.md). Сайт предназначен только для вымышленных записей. Публичный аккаунт сотрудника — часть конкурсного сценария; любой посетитель, вошедший как вымышленный сотрудник, получает его полномочия над демонстрационными заявками.
