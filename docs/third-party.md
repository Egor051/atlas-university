# Код и сторонние компоненты

Собственный код ATLAS Campus распространяется по [MIT](../LICENSE). Знак, иконки и декоративные элементы выполнены средствами SVG/CSS для этого концепта. Официальные логотипы вузов, фотографии, платные изображения и внешние шрифты не используются. Браузер использует системный шрифт; сайт не обращается к CDN, аналитике или внешнему ИИ.

Прямые Python-зависимости загружаются стандартным пакетным менеджером; их исходники и тексты лицензий находятся в установленных пакетах. Указания ниже сверены с метаданными установленных пакетов, а не подменяют условия upstream.

| Компонент | Назначение | Лицензия |
|---|---|---|
| FastAPI | HTTP API | MIT |
| Uvicorn | ASGI-сервер | BSD-3-Clause |
| SQLAlchemy | Работа с БД | MIT |
| Argon2-cffi | Хеширование паролей | MIT |
| Pydantic | Валидация контрактов | MIT |
| Psycopg | Драйвер PostgreSQL | LGPL-3.0-only; библиотека используется отдельно, не модифицируется |
| Pytest | Тесты, только разработка | MIT |
| HTTPX | HTTP-тесты, только разработка | BSD-3-Clause |
| Playwright | Chromium-проверки, только разработка | Apache-2.0 |
| axe-core 4.14.0 | Автоматические проверки доступности, только разработка | MPL-2.0 |

axe-core установлен через `npm ci` по зафиксированному lockfile. Он не входит в браузерные файлы приложения, не загружается пользователем сайта и не изменялся. Исходный проект и лицензия: [dequelabs/axe-core](https://github.com/dequelabs/axe-core), `node_modules/axe-core/LICENSE` после установки. Автоматические правила не являются полной проверкой WCAG.

Для подготовки PDF использованы ReportLab и Pillow из среды инструментов. Segoe UI взят из установленной Windows: проверен флаг OS/2 fsType=8 (editable document embedding); генератор отклоняет запрещённое встраивание и запрет subset. Файл шрифта в исходники не копируется и на веб-сервер не загружается. Основание: [Microsoft Font FAQ, Document embedding](https://learn.microsoft.com/en-us/typography/fonts/font-faq#document-embedding). Генератор поддерживает установленный DejaVu Sans в Linux.

Контейнеры основаны на официальных образах Python, PostgreSQL и Caddy с их upstream-лицензиями; неизменяемые digest и фактически проверенные версии указаны в Dockerfile, compose.yaml и deployment-report. Лицензии базовых слоёв и транзитивных пакетов сохраняются их поставщиками. Установка зависимостей не означает приобретения прав на чужую символику.


Версия 3.2: FFmpeg использован только как локальный инструмент субтитров собственной записи; бинарники не перераспространяются. Фото и чужая графика не добавлялись. Версии браузеров, SQL, образов и свежий аудит runtime указаны в датированных JSON 3.2.
