# ATLAS Campus · дисциплины, преподаватели и переписка

Актуально на 16 ноября 2026 года. [История навигации каталога](navigation-2026-11-11.md).

## Страницы кабинета

| Адрес | Возможности |
|---|---|
| `/app/university` | Каталог институтов, факультетов, кафедр и преподавателей. Поиск по имени, направлению и дисциплине. Фильтры по подразделению и виду результата |
| `/app/university/{faculty}[/{department}[/{teacher}]]` | Страницы уровней с рабочими ссылками на родителей. На профиле есть должность, кафедра, академическая информация, дисциплины, занятия и консультации по МСК, публикации и контактные действия |
| `/app/courses`, `/app/courses/{discipline_id}` | «Мои дисциплины», сквозной поиск и рабочая страница предмета. Вкладки материалов, сведений о дисциплине, расписания, заданий, консультаций и объявлений |
| `/app/courses/materials/{id}` | Страница материала. Прежние адреса `/app/materials` и `/app/materials/{id}` открывают новые страницы с сохранением фильтров каталога или идентификатора материала |
| `/app/materials-admin` | Публикации, правка, доступность и архив в пределах серверных полномочий |
| `/app/material-delegations` | Назначение права управления материалами по конкретной дисциплине или кафедре |
| `/app/direct`, `/app/direct/{id}` | Диалоги, поиск по собеседнику, непрочитанные и страницы истории. Студент выбирает адресата или переходит из профиля. `?recipient={id}` открывает существующую переписку либо форму первого сообщения |
| `/app/teacher` | Работы на проверке, закреплённые группы, текущая неделя, консультации, публикации и переписка с документами |

Текстовые материалы можно прочитать в кабинете и скачать в виде автономного HTML. В редакторе строки `## Заголовок` начинают раздел, пустая строка отделяет абзацы. Для текстовой презентации нужны минимум два озаглавленных слайда. Для готовых вложений поддерживаются PDF, DOCX, XLSX, PPTX, PNG, JPEG, TXT и MD до 5 МиБ на файл. Двоичные данные сохраняются в PostgreSQL или SQLite вместе с записью материала. В кабинете доступно скачивание исходного файла.

Для нового материала редактор по умолчанию предлагает назначенные учебные группы. Опубликованные ранее записи сохраняют доступ для всего кампуса. Доступность проверяется для каждой выдачи списка, карточки, ссылки из задания и загрузки файла.

## API

Все вызовы требуют сеанс. Изменения требуют `X-Requested-With: ATLAS`
и совпадения источника. Клиент передаёт `X-ATLAS-User` для проверки
аккаунта в нескольких вкладках.

| Метод и адрес | Правила |
|---|---|
| GET `/api/university` | `q`, `faculty`, `kind`. Пустой фильтр возвращает верхний уровень |
| GET `/api/university/{faculty}[/{department}[/{teacher}]]` | Каждый дочерний объект проверяется в указанном подразделении. Несовпадение даёт 404 |
| GET `/api/university/me` | Собственный профиль преподавателя |
| GET `/api/disciplines[/{id}]` | Каталог, принадлежность дисциплины к кабинету, число видимых публикаций, преподаватели и ссылка на личные модули |
| GET `/api/disciplines/{id}/activity` | `view=schedule\|works\|consultations`. Только события, работы и записи, доступные студенту по его сеансу |
| GET `/api/announcements?discipline={id}` | Объявления, связанные с дисциплиной. Сервер применяет аудиторию объявления, включая учебную группу |
| GET `/api/materials` | `q`, `kind`, `discipline`, `teacher`, `sort=newest\|updated\|oldest\|title`, `offset`, `limit`. `mine=true` выбирает управляемые публикации, `access` фильтрует по доступности |
| GET `/api/materials/{id}`, `/api/materials/{id}/file` | Метаданные и источник. Вложение или сгенерированный HTML выдаётся через проверяемое скачивание с `Content-Disposition: attachment`, sandbox и `Cache-Control: no-store, private` |
| GET `/api/materials/assignments` | Варианты дисциплин и авторов, доступные издателю |
| POST `/api/materials` | `assignment_id`, `kind`, `title`, `description`, `access` и источник `body`, `url` или `file`. Структура файла содержит `name` и `content` в Base64. Повтор с тем же `Idempotency-Key` возвращает исходный результат |
| PATCH `/api/materials/{id}`, DELETE `/api/materials/{id}?version=N` | Изменение и архивирование по версии. Если в PATCH указан `source=file` без нового файла, вложение сохраняется. Устаревшая версия даёт 409 |
| GET `/api/materials/{id}/history` | Журнал авторов, действий и дат с пагинацией для управомоченного издателя |
| GET, POST, DELETE `/api/materials/delegations[/{id}]` | Список, выдача и отзыв полномочий. Для выдачи передаются `user_id`, `scope=course\|department`, `scope_id`. Только системный администратор |
| GET `/api/teaching/workbench` | Текущие группы и до 20 работ с непроверенными попытками. Только по нагрузке преподавателя |
| GET `/api/direct/recipients[/{id}]` | Студенческий поиск `q` по допущенным преподавателям и офису. Выбранный адресат включает ID существующей пары, когда диалог уже открыт |
| GET `/api/direct/dialogs`, `/api/direct/unread` | Список только собственных диалогов с `q`, `offset`, `limit`. Счётчик непрочитанных для каждой роли |
| GET `/api/direct/dialogs/{id}` | До 50 сообщений. Параметр `before` открывает предыдущую страницу по возвращённому `older_before` |
| POST `/api/direct/dialogs` | `recipient_id` и `message`. Только студент. Первый текст создаёт одну пару или дополняет имеющуюся |
| POST `/api/direct/dialogs/{id}/messages` | `message`. Ответ отправляет участник. В диалоге с преподавателем можно передать `file` в том же формате, что для публикаций. Для повторов используется `Idempotency-Key` |
| GET `/api/direct/dialogs/{id}/messages/{message_id}/file` | Скачивание вложения только участником диалога с повторной проверкой принадлежности сообщения |
| POST `/api/direct/dialogs/{id}/read` | `through_id` подтверждает сообщения собеседника до выбранной записи включительно. Запись должна принадлежать диалогу |
| GET `/api/notifications?filter=direct` | Уведомления получателя личного сообщения. Ссылка ведёт в диалог с повторной проверкой участия |

Клиент экранирует содержимое сообщений и документов. Сервер возвращает 404
постороннему аккаунту при чтении, ответе или отметке. Лимит отправителя
составляет 12 сообщений в минуту и 120 в сутки поверх общих квот. Сообщение
ограничено 3000 символами. Студент может создать до 60 диалогов. История
каждого диалога хранит до 2000 сообщений. Счётчик обновляется при входе,
возврате на вкладку и периодически. Просмотр диалога отмечает только
подтверждённую часть истории и соответствующие уведомления студента.

## Полномочия

| Роль | Уровень доступа |
|---|---|
| Студент | Публикации кампуса и назначения своей учебной группы. Личные работы, модули, консультации и переписка |
| Преподаватель | Публикации по собственным назначениям. Студенты, задания, проверки и посещаемость только по собственной нагрузке. Свои консультации и переписка |
| Ответственный за курс (`coordinator`) | Управление материалами конкретной дисциплины по выданному полномочию |
| Сотрудник кафедры (`department`) | Управление материалами дисциплин конкретной кафедры по выданному полномочию |
| Учебная администрация (`staff`) | Публикации всех дисциплин, объявления, официальные заявки и справки учебного офиса |
| Системный администратор (`admin`) | Управляет полномочиями в каталоге, учебной нагрузкой и утверждением расписания |

Учётной записи ответственного за курс или сотрудника кафедры назначается соответствующая роль. Администратор связывает её с дисциплиной или кафедрой в «Полномочиях по материалам». Ведомости, личные студенческие данные и файлы переписки проверяются собственными правилами доступа.

## Хранение

Миграция `0019_discipline_materials` сохраняет идентификаторы и исходные поля прежних материалов. Она связывает сохранённые учебные модули с дисциплиной при единственном совпадении названия, добавляет файл и доступность в публикации и ссылки из заданий по идентификаторам. Операции с материалами и полномочиями записываются в `workspace_operation_events`. При замене файла журнал сохраняет имя, размер и контрольную сумму прежнего вложения. Текущий файл остаётся доступным управомоченному издателю в архиве. Лимит файлов на одно учебное назначение составляет 128 МиБ с учётом архива, лимит отправителя в личной переписке составляет 64 МиБ.

Миграция `0007_university_library_direct` добавляет:

- `university_faculties`, `university_departments`, `university_teachers`, `university_disciplines`, `university_teaching_assignments`, `university_teaching_slots`.
- `teaching_materials` с авторством через назначение дисциплины, издателем, датами и версией.
- `direct_contacts`, `direct_dialogs`, `direct_messages` с уникальной парой участников, отправителем, временем прочтения и ссылкой на уведомление.

Квитанции безопасного повтора хранятся в существующей таблице
`service_idempotency`. Старая учебная и административная история сохраняется.
Начальный набор содержит четыре аккаунта преподавателей, два подразделения
верхнего уровня, три кафедры и шесть содержательных публикаций. Каталог
создаётся только при `DEMO_MODE=true`. [Миграции](../migrations/README.md).
