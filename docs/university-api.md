# ATLAS Campus 3.3.0. Университет, материалы и переписка

Локальная версия конкурсного концепта от 11 ноября 2026. Каталог описывает
вымышленный университет АТЛАС. [Первый этап, навигация](navigation-2026-11-11.md).

## Страницы кабинета

| Адрес | Возможности |
|---|---|
| `/app/university` | Каталог институтов, факультетов, кафедр и преподавателей. Поиск по имени, направлению и дисциплине. Фильтры по подразделению и виду результата |
| `/app/university/{faculty}[/{department}[/{teacher}]]` | Страницы уровней с рабочими ссылками на родителей. На профиле есть должность, кафедра, академическая информация, дисциплины, занятия и консультации по МСК, публикации и контактные действия |
| `/app/materials`, `/app/materials/{id}` | Поиск, фильтры, чтение и скачивание. Лекции, методические указания, презентации, практические и лабораторные задания, дополнительные материалы |
| `/app/materials-admin` | Публикация, правка и удаление. Доступно офису и преподавателям |
| `/app/direct`, `/app/direct/{id}` | Диалоги, поиск по собеседнику, непрочитанные и страницы истории. Студент выбирает адресата или переходит из профиля. `?recipient={id}` открывает существующую переписку либо форму первого сообщения |
| `/app/teacher` | Рабочий кабинет преподавателя с расписанием, консультациями, публикациями и входом в переписку |

Для демонстрации войдите как Алина и откройте
`/app/university/digital/systems/mikhail-orlov`. Откройте лекцию «Поиск пути
в невзвешенном графе», скачайте файл, вернитесь в профиль и отправьте сообщение.
В отдельном профиле браузера войдите как `orlov.demo` с вымышленным паролем
`AtlasTeach!2026-M` и ответьте из «Личных сообщений». У Алины появится
уведомление. Кира Миронова доступна в поиске по словам «Учебный офис».

Изданные материалы представляют собой автономные HTML-файлы в UTF-8.
Файл создаётся из сохранённого содержания и содержит метаданные и текст.
Для презентаций добавлена навигация между слайдами. В редакторе строки
`## Заголовок` начинают раздел, пустая строка отделяет абзацы. Презентация
содержит минимум два озаглавленных слайда с текстом. Прежний каталог книг
и формуляр остаются на `/app/library`. Формальные обращения и их статусы
остаются на `/app/messages` и `/app/staffmessages`.

## API

Все вызовы требуют сеанс. Изменения требуют `X-Requested-With: ATLAS`
и совпадения источника. Клиент передаёт `X-ATLAS-User` для проверки
аккаунта в нескольких вкладках.

| Метод и адрес | Правила |
|---|---|
| GET `/api/university` | `q`, `faculty`, `kind`. Пустой фильтр возвращает верхний уровень |
| GET `/api/university/{faculty}[/{department}[/{teacher}]]` | Каждый дочерний объект проверяется в указанном подразделении. Несовпадение даёт 404 |
| GET `/api/university/me` | Собственный профиль преподавателя |
| GET `/api/materials` | `q`, `kind`, `discipline`, `teacher`, `offset`, `limit`. `mine=true` выбирает публикации, доступные для управления |
| GET `/api/materials/{id}`, `/api/materials/{id}/file` | Содержание с метаданными и скачиваемый HTML. Файл получает `Content-Disposition: attachment`, политику sandbox и `Cache-Control: no-store, private` |
| GET `/api/materials/assignments` | Варианты дисциплин и авторов, доступные издателю |
| POST `/api/materials` | `assignment_id`, `kind`, `title`, `description`, `body`. Повтор с тем же `Idempotency-Key` возвращает исходный результат |
| PATCH `/api/materials/{id}`, DELETE `/api/materials/{id}?version=N` | Преподаватель управляет материалами по своим назначениям, офис управляет всеми. Устаревшая версия даёт 409 |
| GET `/api/direct/recipients[/{id}]` | Студенческий поиск `q` по допущенным преподавателям и офису. Выбранный адресат включает ID существующей пары, когда диалог уже открыт |
| GET `/api/direct/dialogs`, `/api/direct/unread` | Список только собственных диалогов с `q`, `offset`, `limit`. Счётчик непрочитанных для каждой роли |
| GET `/api/direct/dialogs/{id}` | До 50 сообщений. Параметр `before` открывает предыдущую страницу по возвращённому `older_before` |
| POST `/api/direct/dialogs` | `recipient_id` и `message`. Только студент. Первый текст создаёт одну пару или дополняет имеющуюся |
| POST `/api/direct/dialogs/{id}/messages` | `message`. Ответ отправляет участник. Отправителя определяет сеанс. Для повторов используется `Idempotency-Key` |
| POST `/api/direct/dialogs/{id}/read` | `through_id` подтверждает сообщения собеседника до выбранной записи включительно. Запись должна принадлежать диалогу |
| GET `/api/notifications?filter=direct` | Студенческие уведомления о новых личных сообщениях. Ссылка ведёт в соответствующий диалог |

Клиент экранирует содержимое сообщений и документов. Сервер возвращает 404
постороннему аккаунту при чтении, ответе или отметке. Лимит отправителя
составляет 12 сообщений в минуту и 120 в сутки поверх общих квот. Сообщение
ограничено 3000 символами. Студент может создать до 60 диалогов. История
каждого диалога хранит до 2000 сообщений. Счётчик обновляется при входе,
возврате на вкладку и периодически. Просмотр диалога отмечает только
подтверждённую часть истории и соответствующие уведомления студента.

## Хранение

Миграция `0007_university_library_direct` добавляет:

- `university_faculties`, `university_departments`, `university_teachers`, `university_disciplines`, `university_teaching_assignments`, `university_teaching_slots`.
- `teaching_materials` с авторством через назначение дисциплины, издателем, датами и версией.
- `direct_contacts`, `direct_dialogs`, `direct_messages` с уникальной парой участников, отправителем, временем прочтения и ссылкой на уведомление.

Квитанции безопасного повтора хранятся в существующей таблице
`service_idempotency`. Старая учебная и административная история сохраняется.
Сборка содержит четыре вымышленных преподавателя, два подразделения
верхнего уровня, три кафедры и шесть содержательных публикаций. Каталог
создаётся только в демонстрационном режиме. [Миграции](../migrations/README.md).
